## Introduction

This hands-on session demonstrates a Self-Consistent Field (SCF) calculation using Quantum ESPRESSO.

Participants will learn:

- Prepare QE input file
- Submit calculation using SLURM
- Analyze total energy
- Check convergence


---

## Computational Workflow

The SCF calculation follows these main steps:

```text
Prepare atomic structure

        ↓

Define pseudopotential

        ↓

Run SCF calculation

        ↓

Analyze output energy

        ↓

Check convergence
```
