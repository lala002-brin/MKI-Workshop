# Post Processing

## Overview

Post processing is the analysis stage performed after completing Quantum ESPRESSO calculations.

The purpose of post processing is to extract, transform, and visualize simulation results into meaningful scientific information.

Post processing is commonly performed after:

- SCF calculations
- Geometry optimization
- Band structure calculations
- DOS calculations
- Phonon calculations
- Molecular dynamics simulations

The general workflow is:

```text
Quantum ESPRESSO Calculation

        ↓

Raw Output Files

        ↓

Post Processing Tools

        ↓

Data Analysis

        ↓

Scientific Visualization
```

---

# Quantum ESPRESSO Post Processing Tools

Quantum ESPRESSO provides several utilities for analyzing calculation results.

| Tool | Function |
|---|---|
| `bands.x` | Process band structure data |
| `dos.x` | Calculate density of states |
| `projwfc.x` | Calculate projected DOS |
| `pp.x` | Generate charge density and wave function data |
| `average.x` | Calculate planar averages |
| `plotrho.x` | Visualize charge density |

---

# Charge Density Analysis

Charge density describes the spatial distribution of electrons in a material.

The charge density can be extracted using:

```text
pp.x
```

Example input:

```text
&INPUTPP

prefix = 'material'

plot_num = 0

/

```

Run:

```bash
pp.x < pp.in > pp.out
```

Charge density analysis is useful for studying:

- Electron distribution
- Chemical bonding
- Charge transfer

---

# Electron Density Difference

Charge density difference compares electron distribution before and after interaction.

The analysis helps understand:

- Bond formation
- Charge transfer
- Interface interaction

General workflow:

```text
Calculate Individual Systems

        ↓

Calculate Combined System

        ↓

Subtract Charge Densities

        ↓

Visualize Charge Redistribution
```

# Band Structure Post Processing

After band calculation, the output is processed using:

```text
bands.x
```

Example:

```bash
bands.x < bands.in > bands.out
```

The processed data can be visualized as:

- Energy versus k-point
- High-symmetry path
- Band dispersion

---

# Density of States Post Processing

DOS data generated by:

```text
dos.x
```

can be analyzed to determine:

- Band gap
- Electronic states
- Orbital contribution

Projected DOS:

```text
projwfc.x
```

provides information about contributions from:

- Specific atoms
- Atomic orbitals
- Chemical species

# Example Python Visualization

Example plotting DOS data:

```python
import matplotlib.pyplot as plt

energy = [-5, -3, -1, 1, 3]

dos = [0, 2, 5, 3, 0]

plt.plot(energy, dos)

plt.xlabel("Energy (eV)")

plt.ylabel("DOS")

plt.show()
```
