# Interactive Crystal Structure Viewer · VESTA Style

Visualisasi struktur tiga dimensi untuk praktikum SIESTA, dengan **unit cell otomatis** dari CIF atau VASP POSCAR/CONTCAR, pilihan supercell, pengaturan warna unsur, dan pengukuran jarak antaratom.

!!! warning "Akurasi ilmiah"
    Contoh Cu₂O adalah struktur kristal **ideal sintetis untuk pembelajaran**, bukan hasil optimasi DFT. Diagram ikatan menggunakan perkiraan jarak antaratom dan belum melakukan rekonstruksi ikatan minimum-image melintasi permukaan supercell. CIF nontrivial dengan operasi simetri kompleks tetap perlu diverifikasi di VESTA.

## Format file

- **CIF**: `.cif`, parameter sel dan koordinat atom dari CIF, diproses oleh parser CIF 3Dmol.js.
- **VASP**: `POSCAR`, `CONTCAR`, `.vasp`, `.poscar`, `.contcar`; membutuhkan baris spesies seperti format VASP 5, serta koordinat Direct atau Cartesian.
- **XYZ**: `.xyz` hanya untuk atom/molekul dan tidak memiliki unit cell.

> Untuk struktur SIESTA `.XV` atau `.STRUCT_OUT`, lakukan konversi ke CIF/XYZ dengan alat yang mempertahankan data kisi, lalu verifikasi jumlah atom dan posisi dengan VESTA.
