    First-Principles Calculation Guide

    Quantum ESPRESSO is an open-source package used for first-principles calculations based on Density Functional Theory (DFT).

    This guide provides basic support for preparing, running, and checking Quantum ESPRESSO calculations.

    SCF Calculation

    The Self-Consistent Field (SCF) calculation is the first step to obtain the converged electronic density of a system.

    Run SCF Calculation

    The SCF calculation is performed using the pw.x program.

    Command:

    pw.x -in scf.in > scf.out

    Input file:

    scf.in

    Output file:

    scf.out

    Check SCF Result

    After calculation finishes, check the total energy:

    grep "!" scf.out

    Example output:

    !    total energy              =   -114.523 Ry

    NSCF Calculation

    The Non-Self-Consistent Field (NSCF) calculation is used to obtain additional electronic states.

    It usually follows an SCF calculation.

    Run NSCF Calculation

    Command:

    pw.x -in nscf.in > nscf.out

    Input file:

    nscf.in

    Output file:

    nscf.out

    Calculation Monitoring

    During a running calculation, monitor the output file:

    tail -50 scf.out

    Look for:

    convergence has been achieved

    This indicates that the SCF calculation has reached convergence.

    Density of States (DOS)

    Density of States (DOS) analysis describes the number of available electronic states at different energy levels.

    DOS calculations are useful for understanding electronic properties of materials.

    Band Structure Calculation

    Band structure calculations show the relationship between electronic energy and crystal momentum.

    They are commonly used to identify:

    • Band gap
    • Metallic behavior
    • Electronic dispersion

    Common Problems

    Understanding common errors helps participants troubleshoot calculations more effectively.

    Problem: Missing Pseudopotential File

    Error example:

    cannot find pseudopotential file

    Possible causes:

    • Incorrect pseudopotential filename
    • Wrong pseudo_dir path
    • Missing UPF file

    Check:

    pseudo_dir='./pseudo/'

    Verify the pseudopotential folder:

    ls pseudo/

    Problem: Calculation Does Not Converge

    Error example:

    convergence NOT achieved

    Possible causes:

    • Insufficient number of iterations
    • Incorrect convergence threshold
    • Poor initial structure

    Check the output:

    tail -50 scf.out

    Possible solutions:

    • Adjust convergence parameters
    • Increase iteration limit
    • Check input settings

    Problem: Wrong Input File

    Before running calculations, check:

    ✓ Material structure is correct

✓ Atomic positions are valid

✓ Pseudopotential is available

✓ Cutoff energy is appropriate

✓ K-point settings are prepared
