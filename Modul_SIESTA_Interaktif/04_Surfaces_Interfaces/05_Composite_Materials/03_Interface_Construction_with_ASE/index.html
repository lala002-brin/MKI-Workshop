    Konstruksi Interface dengan ASE

    Atomic-Scale Interface Construction for Composite Materials

    Rekayasa Interface Skala Atom Menggunakan ASE

    Konstruksi interface merupakan tahap penting dalam pemodelan material komposit dan heterostruktur. Tahap ini bertujuan membangun model atomik yang menggambarkan kontak antara dua atau lebih material secara realistis sebelum dilakukan simulasi Density Functional Theory (DFT).

    1. Konsep Dasar Interface Construction

    Dalam material komposit, interface merupakan wilayah kontak antara dua fase material yang memiliki karakteristik berbeda.

    Contoh sistem:

    ZIF-67 / Fe₃O₄ / Cu₂O

    Pada tingkat atom, interface menentukan:

    Parameter Pengaruh
    Susunan atom Menentukan kestabilan struktur
    Jarak antar material Menentukan kekuatan interaksi
    Kesesuaian kisi Mengontrol strain interface
    Orientasi permukaan Menentukan konfigurasi kontak

    Tujuan utama konstruksi interface:

    • menghasilkan struktur atomik yang realistis;
    • mendapatkan kontak antar material yang stabil;
    • mempersiapkan model untuk simulasi DFT.

    3. Workflow Konstruksi Interface Menggunakan ASE

    1. Membaca struktur kristal awal 2. Menentukan bidang permukaan 3. Membuat slab permukaan 4. Melakukan lattice matching 5. Membuat supercell 6. Menyusun interface 7. Melakukan optimasi awal

    ASE digunakan karena menyediakan fungsi untuk:

    • membaca struktur kristal;
    • memanipulasi atom;
    • membuat slab;
    • membuat supercell;
    • menyusun struktur interface.

    4. Persiapan Struktur Kristal Awal

    Tahap pertama adalah menyediakan struktur bulk dari masing-masing material.

    Format yang umum digunakan:

    Format Keterangan
    CIF Struktur kristal eksperimen
    POSCAR Struktur VASP
    XYZ Koordinat atom sederhana

    Sumber struktur:

    • database kristal;
    • Materials Project;
    • literatur eksperimen.

    4.1 Validasi Struktur Awal

    Sebelum membuat interface, struktur harus diperiksa.

    Parameter utama:

    Parameter Fungsi
    Parameter kisi Menentukan ukuran sel
    Space group Menentukan simetri
    Posisi atom Memastikan konfigurasi benar
    Komposisi atom Memastikan stoikiometri

    Struktur yang salah pada tahap awal akan menyebabkan:

    • interface tidak realistis;
    • energi tidak akurat;
    • interpretasi DFT menjadi bias.

    5. Membaca Struktur Menggunakan ASE

    Contoh workflow:

    Import library ASE

        ↓

Membaca file CIF

        ↓

Memeriksa struktur

    Contoh kode:

    from ase.io import read

structure = read("material.cif")

print(structure)

print(structure.cell)

    Informasi yang diperoleh:

    • jumlah atom;
    • jenis elemen;
    • parameter kisi;
    • koordinat atom.

    6. Surface Slab Construction

    Struktur bulk belum dapat langsung digunakan untuk membangun interface.

    Tahap berikutnya adalah membuat permukaan atau surface slab.

    Konsep:

    Bulk Crystal

    ↓

    Pemotongan bidang kristal

    ↓

    Surface Slab

    Surface slab merepresentasikan bagian permukaan material yang akan berinteraksi dengan material lain.

    6.1 Pemilihan Orientasi Permukaan

    Orientasi permukaan ditentukan menggunakan indeks Miller.

    Contoh:

    Fe₃O₄ (111)

    Pemilihan bidang permukaan mempertimbangkan:

    • kestabilan termodinamika;
    • energi permukaan;
    • ketersediaan situs aktif;
    • relevansi eksperimen.

    6.2 Parameter Surface Slab

    Parameter penting:

    Parameter Fungsi
    Miller index Menentukan orientasi permukaan
    Jumlah lapisan atom Menentukan ketebalan slab
    Vacuum layer Mencegah interaksi periodik
    Termination Menentukan atom permukaan

    7. Lattice Matching

    Material yang berbeda biasanya memiliki parameter kisi yang berbeda.

    Perbedaan ini disebut lattice mismatch.

    Lattice mismatch perlu dikontrol karena dapat menyebabkan:

    • strain berlebihan;
    • distorsi struktur;
    • perubahan sifat elektronik.

    7.1 Perhitungan Lattice Mismatch

    Persamaan:

    \[ Mismatch(\%)= \frac{|a_1-a_2|} {a_2} \times100 \]

    Keterangan:

    Simbol Penjelasan
    a1 Parameter kisi material pertama
    a2 Parameter kisi material kedua

    Kriteria umum:

    Nilai mismatch Interpretasi
    < 5% Sangat sesuai
    5-10% Masih dapat diterima
    >10% Membutuhkan optimasi lebih lanjut

    8. Supercell Construction

    Setelah melakukan analisis lattice matching, tahap berikutnya adalah membangun supercell.

    Supercell merupakan pengulangan struktur unit cell menjadi ukuran yang lebih besar untuk memperoleh area kontak interface yang representatif.

    Konsep:

    Unit Cell

    ↓

    Supercell

    ↓

    Interface Model

    8.1 Tujuan Pembuatan Supercell

    Pembuatan supercell bertujuan untuk:

    • meningkatkan jumlah atom kontak antar material;
    • mengurangi efek batas periodik;
    • mengakomodasi perbedaan parameter kisi;
    • menghasilkan model interface yang lebih realistis.

    8.2 Strategi Pemilihan Ukuran Supercell

    Ukuran supercell harus mempertimbangkan keseimbangan antara:

    Faktor Pertimbangan
    Akurasi Jumlah atom harus cukup untuk merepresentasikan interface
    Komputasi Ukuran sistem tidak terlalu besar
    Stabilitas Strain harus tetap terkendali

    Supercell terlalu kecil:

    • interface kurang representatif;
    • interaksi atom terbatas.

    Supercell terlalu besar:

    • waktu komputasi meningkat;
    • kebutuhan memori lebih tinggi.

    8.3 Contoh Supercell Interface

    Contoh:

    Material A:

    3 × 3 supercell

    Material B:

    4 × 4 supercell

    Kemudian dilakukan penyesuaian:

    Material A

      +

Material B

      ↓

Interface Supercell

    9. Interface Assembly

    Interface assembly merupakan tahap menggabungkan dua surface slab menjadi satu sistem heterostruktur.

    Proses:

    Surface Material A

    ↓

    Penempatan Surface Material B

    ↓

    Penentuan Jarak Antar Permukaan

    ↓

    Optimasi Struktur

    9.1 Penentuan Posisi Awal Interface

    Parameter yang harus ditentukan:

    Interlayer Distance

    Jarak awal antara dua permukaan.

    Rentang awal yang umum:

    2 - 4 Å

    Jarak ini kemudian diperbaiki melalui geometry optimization.

    9.2 Translasi Permukaan

    Selain jarak vertikal, posisi lateral juga perlu diuji.

    Variasi:

    • pergeseran arah x;
    • pergeseran arah y;
    • posisi atom kontak.

    Tujuan:

    Menemukan konfigurasi dengan energi paling rendah.

    9.3 Surface Termination

    Satu material dapat memiliki beberapa kemungkinan atom permukaan.

    Contoh:

    Cu₂O:

    Cu termination

    atau

    O termination

    Perbedaan termination dapat menyebabkan:

    Perubahan Dampak
    Distribusi atom Mengubah kontak interface
    Muatan permukaan Mengubah transfer elektron
    Energi interface Mengubah kestabilan

    10. Interface Configuration Screening

    Dalam penelitian tingkat lanjut, satu model interface biasanya belum cukup.

    Beberapa konfigurasi perlu dibandingkan:

    Model Variasi
    Model A Orientasi permukaan berbeda
    Model B Jarak interface berbeda
    Model C Surface termination berbeda
    Model D Struktur dengan defect

    Setiap model dievaluasi berdasarkan:

    • energi total;
    • stabilitas struktur;
    • kualitas kontak atom.

    11. Optimasi Awal Struktur Interface

    Setelah interface terbentuk, dilakukan optimasi geometri.

    Tujuan:

    • memperoleh konfigurasi energi minimum;
    • menghilangkan overlap atom;
    • memperbaiki jarak antar atom.

    Parameter umum:

    Parameter Nilai Rekomendasi
    Metode Conjugate Gradient
    Kriteria gaya < 0.02 eV/Å
    Optimasi posisi atom Aktif
    Optimasi sel Sesuai kebutuhan

    11.1 Pemeriksaan Setelah Optimasi

    Setelah optimasi dilakukan pemeriksaan:

    ✓ Struktur tidak mengalami keruntuhan

    ✓ Tidak ada atom yang terlalu dekat

    ✓ Jarak interface tetap realistis

    ✓ Energi total menurun

    ✓ Konfigurasi stabil

    12. Export Interface untuk Perhitungan DFT

    Setelah model interface selesai, struktur dapat digunakan untuk simulasi menggunakan software DFT seperti SIESTA.

    Output yang diperlukan:

    Data Fungsi
    Koordinat atom Posisi awal simulasi
    Vektor kisi Informasi sel periodik
    Jenis atom Menentukan spesies
    Jumlah atom Konfigurasi sistem

    Format akhir:

    .fdf

    untuk input SIESTA.

    14. Best Practice untuk Penelitian Interface

    Research Recommendation

    Interface yang baik harus dibangun berdasarkan pertimbangan fisika material, bukan hanya menggabungkan dua struktur secara geometris.

    Hal yang perlu dilaporkan dalam penelitian:

    • alasan pemilihan orientasi permukaan;
    • nilai lattice mismatch;
    • ukuran supercell;
    • jarak awal interface;
    • metode optimasi;
    • kriteria kestabilan.

    16. Implementasi Konstruksi Interface Menggunakan ASE

    16.1 Struktur Data dalam ASE

    ASE merepresentasikan struktur atom sebagai objek Atoms.

    Setiap objek menyimpan:

    Komponen Fungsi
    Chemical symbols Jenis atom
    Atomic positions Koordinat atom
    Cell vectors Ukuran dan bentuk sel
    Periodic boundary condition Sistem periodik

    Konsep dasar:

    Crystal Structure

      ↓

      ↓

Manipulasi Struktur

      ↓

Interface Model

    16.2 Membuat Supercell Menggunakan ASE

    Supercell dapat dibuat dengan melakukan replikasi struktur awal.

    Konsep:

    Unit Cell

      ×

Replication Matrix

      ↓

Supercell

    Contoh:

    2 × 2 × 1

    atau

    3 × 3 × 1

    untuk model permukaan.

    16.3 Persiapan Surface Slab

    Dalam ASE, surface slab dibuat dengan menentukan:

    • struktur bulk;
    • orientasi Miller index;
    • jumlah lapisan;
    • vacuum region.

    Parameter utama:

    Parameter Fungsi
    Miller index Menentukan bidang kristal
    Layers Ketebalan slab
    Vacuum Ruang kosong antar permukaan

    18. Pembangunan Interface Dua Material

    Interface dibangun dengan menggabungkan:

    Slab Material A

        ↓

    Hal yang harus diperhatikan:

    • posisi relatif kedua slab;
    • jarak kontak;
    • orientasi permukaan.

    18.1 Penentuan Jarak Interface Awal

    Jarak awal digunakan sebagai tebakan sebelum optimasi.

    Variasi umum:

    Jarak Kondisi
    <2 Å Risiko overlap atom
    2-4 Å Kandidat awal
    >5 Å Interaksi terlalu lemah

    Untuk penelitian yang ketat, beberapa variasi jarak dapat dibandingkan.

    18.2 Translational Search

    Posisi lateral permukaan dapat divariasikan:

    Menemukan:

    21. Ukuran Sistem dan Pertimbangan Komputasi

    Interface biasanya memiliki jumlah atom lebih besar dibanding bulk.

    Pertimbangan:

    Faktor Dampak
    Jumlah atom Meningkatkan waktu komputasi
    Ukuran supercell Meningkatkan akurasi
    Vacuum Mempengaruhi ukuran sel
    K-point Mempengaruhi biaya SCF

    Strategi:

    • mulai dengan model kecil;
    • lakukan validasi;
    • tingkatkan ukuran jika diperlukan.

    22. Kriteria Model Interface Siap DFT

    26. Advanced Interface Construction Considerations

    Pada penelitian material komposit tingkat lanjut, konstruksi interface tidak hanya berfokus pada penggabungan dua struktur, tetapi juga mempertimbangkan aspek fisika dan kimia yang menentukan kualitas model.

    Beberapa aspek penting:

    • orientasi kristal;
    • konfigurasi atom permukaan;
    • strain interface;
    • jumlah lapisan slab;
    • ukuran supercell;
    • kondisi periodik.

    26.1 Pemilihan Orientasi Interface

    Orientasi interface menentukan jumlah atom yang mengalami kontak langsung.

    Contoh:

    Interface:

    Fe₃O₄ (111)

      /

Cu₂O (111)

    berbeda sifatnya dengan:

    Fe₃O₄ (001)

      /

Cu₂O (110)

    Perbedaan orientasi menyebabkan perubahan:

    Parameter Dampak
    Jumlah atom kontak Mengubah kekuatan interaksi
    Susunan atom Mengubah koordinasi
    Distribusi elektron Mengubah sifat elektronik
    Energi interface Mengubah stabilitas

    26.2 Interface Strain Engineering

    Ketidaksesuaian kisi menyebabkan strain pada interface.

    Dua jenis strain:

    Tensile Strain

    Terjadi ketika:

    Material interface tertarik lebih besar.

    Dampak:

    • perubahan panjang ikatan;
    • perubahan orbital elektronik.

    Compressive Strain

    Terjadi ketika:

    Material mengalami tekanan dari pasangan interface.

    Dampak:

    • perubahan jarak atom;
    • perubahan energi permukaan.

    26.3 Pengaruh Strain terhadap Sifat Material

    Strain dapat memengaruhi:

    • band gap;
    • posisi pita energi;
    • aktivitas katalitik;
    • energi adsorpsi.

    Karena itu, strain bukan hanya masalah geometris, tetapi juga parameter desain material.

    27. Interface dengan Defect

    Dalam material nyata, interface hampir tidak pernah sempurna.

    Defect dapat muncul akibat:

    • proses sintesis;
    • ketidaksempurnaan kristal;
    • kehilangan atom.

    Model komputasi dapat memasukkan:

    • vacancy;
    • substitution;
    • interstitial defect.

    27.1 Oxygen Vacancy pada Interface

    Oxygen vacancy merupakan defect yang sering dipelajari pada oksida logam.

    Contoh:

    Fe₃O₄

    O removed

         ↓

Oxygen Vacancy

    Efek:

    • meningkatkan densitas elektron;
    • menciptakan situs aktif;
    • mengubah mekanisme transfer elektron.

    27.2 Defect pada ZIF-67

    Pada MOF seperti ZIF-67, defect dapat berupa:

    • missing linker;
    • koordinasi logam tidak sempurna;
    • open metal site.

    Dampak:

    • meningkatkan akses molekul;
    • meningkatkan interaksi adsorpsi;
    • mengubah lingkungan Co.

    33. Penutup

    Konstruksi interface menggunakan ASE merupakan tahap penting dalam penelitian material komposit berbasis simulasi atomik.

    Model interface yang baik harus:

    • memiliki dasar kristalografi yang jelas;
    • memiliki konfigurasi atom realistis;
    • mempertimbangkan kesesuaian kisi;
    • melalui validasi struktur;
    • siap digunakan untuk simulasi DFT.

    Dengan workflow yang sistematis, ASE memungkinkan peneliti membangun model heterostruktur kompleks secara efisien dan reproduktif.

    ZIF-67
