3 · Ini fungsinya apa?

K-point menentukan jumlah titik untuk menyampel Brillouin zone. Mesh terlalu kasar berpotensi memberi energi tidak akurat; terlalu rapat memakan waktu komputasi. Uji konvergensi membandingkan energi saat mesh dipadatkan agar kita bisa memilih mesh yang efisien tanpa perubahan energi bermakna.

Cara membaca: grafik pertama menunjukkan perubahan energi, grafik kedua menunjukkan |E(mesh) − E(mesh terpadat)| dalam meV/atom. Label “indikasi” hanya muncul jika sedikitnya empat data terurut tersedia, ada dua mesh lebih rapat setelah kandidat, dan semua energi sejak kandidat tetap berada dalam toleransi terhadap referensi akhir. Hasil bukan pembuktian konvergensi mutlak; tambahkan mesh lebih rapat dan periksa sifat yang diteliti (gaya, tegangan, energi relatif) bila perlu.

4 · Cara menjalankan di Quantum ESPRESSO (ringkas)
  1. Siapkan scf.in yang sama untuk semua percobaan: struktur, UPF, cutoff, smearing, spin, dan opsi SCF tetap.
  2. Ubah hanya bagian K_POINTS automatic, misalnya 2 2 1 0 0 0, lalu 3 3 1 0 0 0, 4 4 1 0 0 0, dst. Mesh kz=1 lazim untuk slab dengan vakum sepanjang vektor c.
  3. Jalankan masing-masing input sebagai pekerjaan terpisah (gunakan prefix/outdir berbeda untuk menghindari bentrok): pw.x -in scf_k4.in > scf_k4.out.
  4. Cari baris ! total energy = ... Ry di output dan pastikan SCF memang konvergen, lalu masukkan mesh beserta energi ke tabel.
  5. Periksa grafik dan ΔE; pilih mesh yang cukup rapat, kemudian ulangi bila perlu dengan mesh lebih tinggi untuk validasi.
